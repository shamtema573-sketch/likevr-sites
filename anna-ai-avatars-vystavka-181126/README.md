# AI-консультант для выставки · LikeVR (V5)

Статическая презентация из десяти слайдов и отдельный калькулятор. Для локального просмотра запустите `python3 -m http.server 8000` в этой папке и откройте `http://localhost:8000/`. Для калькулятора доступен адрес `/calculator.html`.

- `index.html` — презентация с прямыми ссылками на каждый слайд, стрелками, клавиатурной навигацией и свайпами.
- `calculator.html` — отдельная страница калькулятора. При переходе из презентации сохраняются выбранные опции.
- `config.js` — общие цены, параметры эксплуатации и контакты.
- `assets/likevr-character.mp4` — оптимизированная копия оригинального видео LikeVR. Обложка и постер взяты из этого видео.
- `index.html?view=a#visuals` — вариант A с изображением Ava из демо townbox.
- `index.html?view=b#visuals` — вариант B с карточкой WebGPU и ссылкой на демо. Открывается по умолчанию.

В репозитории Освея файлы предложения размещаются в папке `anna-expo/` ветки `main`. Все ссылки на ресурсы относительные. Действующий сайт может обслуживаться из корня той же ветки.
