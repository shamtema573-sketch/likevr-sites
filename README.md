# LikeVR — сайты проектов

Единый публичный каталог статических сайтов LikeVR. Каждый проект живёт в отдельной папке и получает отдельную ссылку. Сайты в старых репозиториях не переносим и не меняем.

> Репозиторий публичный. Загружайте только материалы, цены и контакты, разрешённые к публикации. Никогда не добавляйте токены, пароли, внутреннюю переписку и закрытые документы.

## Папка проекта

В корне репозитория создайте папку проекта с коротким ASCII-slug в нижнем регистре, слова разделяйте дефисом. Для проекта с хэштегом #Анна_AIАватары_Выставка_181126 используйте папку `anna-ai-avatars-vystavka-181126`. Сам хэштег сохраните в заголовке и карточке проекта.

    anna-ai-avatars-vystavka-181126/
    ├── index.html       # готовая главная страница
    ├── assets/          # CSS, JS, изображения, видео и медиа
    └── README.md        # хэштег, описание, цены, статус, ссылки

Не кладите сайт в корень репозитория и не заменяйте корневые index.html или README.md.

## Прямая загрузка сайта Анны

**Загрузить файлы:** https://github.com/shamtema573-sketch/likevr-sites/upload/main/anna-ai-avatars-vystavka-181126/

**После публикации сайт будет здесь:** https://shamtema573-sketch.github.io/likevr-sites/anna-ai-avatars-vystavka-181126/

Если в окне пустая область «Drag files here», файлы ещё не выбраны. Добавьте файлы сборки, дождитесь их появления в списке, введите сообщение коммита и нажмите **Commit changes**. Пока коммит не создан, публикации нет.

## Загрузка через GitHub в браузере

1. Откройте https://github.com/shamtema573-sketch/likevr-sites/upload/main/<slug>, заменив <slug> согласованным именем папки.
2. Загрузите корневые файлы сайта в эту папку. Для папки с медиа откройте https://github.com/shamtema573-sketch/likevr-sites/upload/main/<slug>/assets и загрузите её файлы туда. Для каждой вложенной папки повторите этот шаг с её путём, чтобы GitHub не сложил файлы из разных папок вместе.
3. Дождитесь окончания передачи файлов. Введите понятное сообщение коммита, например `Publish <slug> site files`, оставьте **Commit directly to the main branch** и нажмите **Commit changes**. Пока commit не создан, файлы не опубликованы.
4. Проверьте вкладку **Code**: структура должна совпадать со сборкой, а коммиты должны менять только папку этого проекта. Можно загрузить файлы несколькими коммитами; до последнего коммита сайт может быть неполным.

Для сайта со многими вложенными файлами удобнее `git push`; если API/CLI недоступны, используйте браузер и загружайте содержимое по папкам, как описано выше.

## Настройки и адреса

GitHub Pages настроен один раз: **Settings → Pages → Deploy from a branch → main → /(root)**. Для новых папок Pages отдельно не включайте.

- Каталог проектов: https://shamtema573-sketch.github.io/likevr-sites/
- Сайт проекта: https://shamtema573-sketch.github.io/likevr-sites/<slug>/
- Исходники: https://github.com/shamtema573-sketch/likevr-sites/tree/main/<slug>/

Для ссылок на стили, скрипты и медиа используйте относительные пути, например `assets/styles.css`, а не `/assets/styles.css`. У каждого сайта должен быть `index.html` в своей папке.

## Карточка и проверка перед передачей

После публикации добавьте проект в корневой `index.html` каталога: хэштег, название, краткое описание, ссылка и статус проверки. В карточке проекта и его `README.md` укажите согласованную стоимость, когда её разрешено показывать. Не подставляйте предположительные цены.

Перед передачей ссылки проверьте, что Pages deployment завершился успешно, сайт открывается по своей папке, все разделы, изображения, видео, калькуляторы, ссылки и кнопки работают, а страница удобна на телефоне. После правок проверяйте опубликованную версию, а не только исходник на GitHub.
