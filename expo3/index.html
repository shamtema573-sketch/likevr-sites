Устройство решения

Три киоска работают одновременно

У каждого посетителя своя сессия. Все три киоска обращаются к общей базе примерно из 50 PDF.

  1. Подойти к киоскуВыбрать свободную точку
  2. Задать вопросОбратиться голосом
  3. Поиск в документахAI находит относящиеся к вопросу сведения
  4. Подготовка ответаAI формулирует ответ по материалам
  5. Голосовой ответПерсонаж озвучивает ответ
  6. Передача запросаПосетитель может оставить контакты

Если в документах недостаточно данных, консультант может предложить передать вопрос менеджеру.
