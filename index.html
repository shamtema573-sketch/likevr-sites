Сайты проектов

Отдельная страница для каждого проекта LikeVR. Новые сайты публикуются в собственных папках, не меняя остальные проекты.

Опубликованные проекты

Проекты добавляются сюда после загрузки и проверки публикации.

Карточка проекта должна содержать его хэштег, короткое описание, ссылку, статус проверки и подтверждённую к публикации информацию о стоимости.

Для команды: см. инструкцию по добавлению и публикации сайтов.
